Online Medical Appointment Booking System
===================================
This project is a role-based web application designed to connect patients, doctors, and admins through a secure online medical appointment platform.
It allows users to search for doctors and services, book appointments efficiently.
Built with React (frontend), Node.js (backend), and MongoDB (database), the system provides a modern and scalable dental clinic booking solution.

Features
===============

User Registration & Login
Patients and doctors can create accounts with secure authentication.

Role-Based Access Control
Separate dashboards and permissions for Patients, Doctors, and Admins.

Doctor Profile Management
Doctors can add or update details such as specialization, experience, availability, and fees.

Search & Filter Doctors
Patients can find doctors from search bar.

Appointment Booking & Management
Patients can request appointments; doctors can approve or cancel them.

Admin Panel
Administrators can verify doctors, manage users, and oversee appointments.

Profile Management
All roles can update personal or professional information.

Responsive UI
Works seamlessly on desktop and mobile browsers.

Technology Stack
=======================

Frontend: React.js

Backend: Node.js with Express.js

Database: MongoDB / Cloudinary

Authentication: JSON Web Tokens (JWT)

Styling: CSS / Tailwind 

API Communication: Axios 

Requirements
===================

Node.js v20.10.0

MongoDB v8.0.11

npm 10.2.3

Setup and Installation
=============================
1. Install Node.js and MongoDB
2. Backend Setup
- Open a terminal in the backend folder.
- run followings in terminal.
npm install
npm run server
3. Frontend Setup
-Open a terminal in the frontend folder.
- run followings in terminal.
npm install
npm run dev
4. Admin Setup
-Open a terminal in the admin folder.
- run followings in terminal.
npm install
npm run dev
5.Access the Application
Open browser and go to: http://localhost:_port_number_from_terminal_
